# Tugas 3 - Pemrograman Web

Repositori ini berisi pengerjaan **Tugas Individu 3** Mata Kuliah Pengembangan Aplikasi Web.

## Deskripsi Tugas
Membuat halaman web pendaftaran interaktif dan detail informasi pendaftar menggunakan HTML5 (Form & Table) dan CSS.

## Struktur Folder
* `task_3/index.html` - Halaman form pendaftaran (method GET)
* `task_3/detail.html` - Halaman detail informasi pendaftar (dummy data)
* `task_3/style.css` - Lembar gaya CSS (Layout, Form, & Tabel)

## Fitur & Spesifikasi
- Form pendaftaran menggunakan `method="GET"` yang melempar *query string* ke `detail.html`.
- Menggunakan minimal 3 jenis selector CSS (Element, Class, dan ID Selector).
- Styling layout, box, form controls, dan tabel data (*zebra stripes* & border).
